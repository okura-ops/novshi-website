# vendor-logos — 対外用ツール連携マップ 公式ロゴアセット台帳

> **用途限定**: 本フォルダは「novshiが利用するツールの連携マップ（対外用）」でClaude Designが実ロゴ版を制作するための素材置き場です。**website本体（novshi.co.jp のページUI）では使用しません**。
> **改変禁止**: 各社の原本をそのまま格納しています。再配色・トリミング・変形・アウトライン化・他マークとの結合は一切行いません。マップ制作時も原本のまま配置してください。
> **出所限定**: 各社の公式ブランド／プレスキットページからのみ取得。seeklogo等の非公式アグリゲーターは使用していません。

取得実施日: 2026-07-09 ／ 対象14ツール（Google Workspaceを4製品に分解）

## モノグラム代替リスト（自製）

公式ロゴが取得不可・または第三者利用が禁止/不適のため、モノトーンで自製のワードマーク/モノグラムを用います。

| ツール | 理由 | 代替案 |
|:---|:---|:---|
| notion | 公式が第三者のロゴ単独利用を明示禁止 | 自社タイプで「Notion」ワードマーク、または許容表現の記述 |
| airwork | 公式DL資産なし・リクルート商標は許諾制 | モノトーンの「AirWORK」ワードマーク or 「A」モノグラム |
