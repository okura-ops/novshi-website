## Phase B 差し替え手順（推奨）

1. 本台帳で識別子を選ぶ。
2. `grep -rn "TODO:COPY <id>" src/` で該当行へ飛ぶ。
3. マーカー直後のテキストブロックを確定コピーへ差し替える。
4. 差し替え済みのブロックはマーカーを削除し、本台帳の該当行も削除する。
5. `docs/operations/writing_style.md`（AI感の排除）を通してからコミット。
